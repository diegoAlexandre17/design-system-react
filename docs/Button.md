# Button

> `src/components/ui/button.tsx`

```tsx
<Button
  variant="..."  // default | destructive | success | outline | secondary
                 // | ghost | link | tab | tab-active
  size="..."     // default | sm | lg | icon | icon-lg
/>
```

**Variantes:**
- `default`
- `destructive`
- `success`
- `outline`
- `secondary`
- `ghost`
- `link`
- `tab`
- `tab-active`

**Tamaños:**
- `default`
- `sm`
- `lg`
- `icon`
- `icon-lg`

**Ejemplo:**
```tsx
<Button variant="default" size="default">Guardar</Button>
```

**Página de ejemplo:** `src/pages/ButtonsPage.tsx`
