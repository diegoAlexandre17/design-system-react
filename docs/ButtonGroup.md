# ButtonGroup

> `src/components/ui/button-group.tsx`

```tsx
<ButtonGroup
  orientation="..."  // horizontal | vertical
/>
```

**Orientaciones:**
- `horizontal`
- `vertical`

**Ejemplo:**
```tsx
<ButtonGroup>
  <Button variant="tab">Datos personales</Button>
  <Button variant="tab-active">Datos laborales</Button>
</ButtonGroup>
```

Helpers exportados: `ButtonGroupSeparator`, `ButtonGroupText`.

**Página de ejemplo:** `src/pages/ButtonsPage.tsx`
