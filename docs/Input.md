# Input

> `src/components/ui/input.tsx`

```tsx
<Input
  size="..."   // sm | md | lg
/>
```

**Tamaños:**
- `sm` (h-6, text-xs)
- `md` (h-8.5, text-sm — default)
- `lg` (h-10, text-base)

**Ejemplo:**
```tsx
<Input size="md" placeholder="Karen" />
```

**Página de ejemplo:** `src/pages/InputPage.tsx`
